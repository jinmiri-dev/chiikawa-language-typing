# 직접 해야 할 일

계정 가입, 키 발급, 기기 시험처럼 개발자 본인만 할 수 있는 일이다. 키는 채팅·이슈·커밋에 붙여 넣지 않는다. 배포에서는 Cloudflare Worker 비밀값에만 둔다.

## 끝난 것 (2026-11-05)

- 유튜브 검색(Google Cloud), 자막(SearchAPI), 넷플릭스 추천(TMDB) 키 → Worker 비밀값
- 중계 서버 배포: `https://language-grade1.jinmiri-dev.workers.dev` (`/health` 로 확인)
- GitHub 변수 `VITE_WORKER_ORIGIN` → 사이트가 중계 서버를 쓴다
- Dependabot PR #1~#6 닫음

## 남은 것

### 1. 휴대폰 입력 시험 (15분, 휴대폰 키 안내를 열려면 필요)

1. 휴대폰에서 `https://jinmiri-dev.github.io/chiikawa-language-typing/#/lab/input` 을 연다(첫 화면에는 링크가 없다).
2. 언어와 예문을 고르고 입력칸에 친다.
3. "쓰는 키보드" 칸에 키보드 이름(예: iPhone 일본어 12키 플릭)을 적고 "결과 내려받기".
4. 일본어 12키 플릭, 일본어 QWERTY 로마자, 대만어 주음은 꼭, 중국어 병음·몽골어 키릴은 되면.
5. 받은 JSON 을 PC 로 옮기고 위치를 알려 준다.

### 2. 사용량 확인 (가끔)

- searchapi.io 대시보드: 남은 무료 횟수. 영상 하나 열 때 2~4회 쓴다. 바닥나면 새 영상 자막이 안 열린다(이미 연 영상·추천 영상 중 연 것은 30일 캐시).
- Google Cloud › API 및 서비스 › YouTube Data API v3 › 할당량: 하루 10,000(검색 한 번 약 100). 서버가 하루 검색 90번으로 막는다.
- 카드를 등록하지 않았으면 넘쳐도 요금은 나오지 않고 그날 기능만 멈춘다.

### 3. 공개 전에

- 먼작귀 이미지 사용 범위를 확인한다. 확인 전에는 그림 파일(`public/friends/`, `public/cards/`)을 저장소에 커밋하지 않는다. 지금 사이트는 이름 배지로 보인다.
- 기본 연습 문장과 뜻을 그 언어를 아는 사람이 한 번 봐 주면 좋다.

### 4. 선택: Azure (목소리·번역)

넣으면 여자/남자 목소리와, 한국어 자막이 없는 영상의 자동 번역 뜻이 켜진다. 없어도 기기 목소리로 읽는다. 가입이 막히면 집 와이파이·개인 Microsoft 계정·다른 카드로 다시 해 본다.
