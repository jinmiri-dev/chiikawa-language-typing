# 직접 해야 할 일

계정 가입, 키 발급, 저장소 설정처럼 개발자 본인만 할 수 있는 일이다. 키는 채팅·이슈·커밋에 붙여 넣지 않는다. 로컬에서는 `.env`(커밋 안 됨), 배포에서는 Cloudflare Worker 비밀값에만 둔다.

## 지금 하면 좋은 것 (5분)

GitHub 저장소 → Settings에서 켠다.

| 위치 | 켤 것 | 이유 |
|---|---|---|
| Advanced Security | Dependabot alerts, Dependabot security updates | 취약한 패키지를 알려 주고 고치는 PR을 연다 |
| Advanced Security | Secret scanning, Push protection | 실수로 키를 커밋하면 푸시 단계에서 막는다 |
| Advanced Security | Private vulnerability reporting | `SECURITY.md`가 이 경로로 제보를 받는다 |
| Branches → Add rule (`main`) | Require status checks: `check`, `analyze (javascript-typescript)`, `analyze (actions)` | 검사가 실패한 코드는 main에 들어가지 않는다 |

열려 있는 Dependabot PR #1~#6은 닫는다. #1~#5(Actions 버전 올리기)는 이미 커밋 SHA 고정으로 반영했고, #6(@types/node 26)은 Node 24를 쓰므로 받지 않는다(설정에서 앞으로 제외됨).

## 단계 0: 휴대폰 입력 시험

1. 휴대폰에서 사이트 → "내 키보드로 입력 시험하기"를 연다.
2. 일본어(12키 플릭, QWERTY 로마자)와 대만어(주음)로 예문을 한 줄씩 친다.
3. "키보드 이름" 칸에 쓰는 키보드를 적고 JSON을 내려받아 보내 준다.

이 결과로 휴대폰 키 안내를 실제 조합 방식에 맞춘다.

## 단계 2 전에: API 키 (Worker 만들 때 함께 넣는다)

모두 무료 등급으로 시작한다. 결제 수단을 요구하면 예산 알림을 0원 근처로 걸어 둔다.

| 서비스 | 쓰는 곳 | 할 일 |
|---|---|---|
| Google Cloud | 유튜브 검색 | 프로젝트 만들기 → YouTube Data API v3 사용 설정 → API 키 발급 → 키 제한에서 "YouTube Data API v3"만 허용 |
| 자막 서비스(SearchAPI 등) | 유튜브 자막 가져오기 | 가입 후 API 키 발급. 무료 횟수를 확인한다 |
| Azure Speech | 여성/남성 목소리 듣기 | Azure 가입 → Speech 리소스(F0 무료) 만들기 → 키와 지역(예: koreacentral) 기록 |
| Azure Translator | 한국어 뜻 자동 번역 | 같은 Azure 계정에서 Translator 리소스(F0) 만들기 |
| TMDB | 넷플릭스 작품 추천 | 가입 → Settings → API에서 키 발급. 화면에 TMDB 출처 문구를 넣는다 |
| Cloudflare | 키를 숨기는 중계 서버 | 가입 → `npx wrangler login` → KV 만들기 → 아래처럼 비밀값 넣기 |

```bash
npx wrangler secret put YOUTUBE_API_KEY
```

같은 방식으로 `TRANSCRIPT_API_KEY`, `AZURE_SPEECH_KEY`, `AZURE_SPEECH_REGION`, `AZURE_TRANSLATOR_KEY`, `TMDB_API_KEY`를 넣는다. Worker 주소가 정해지면 GitHub 저장소 Settings → Variables에 `VITE_WORKER_ORIGIN`으로 넣는다(CSP가 이 주소만 허용한다).
