# 직접 해야 할 일

계정 가입, 키 발급, 저장소 설정처럼 개발자 본인만 할 수 있는 일이다. 키는 채팅·이슈·커밋에 붙여 넣지 않는다. 로컬에서는 `.env`(커밋 안 됨), 배포에서는 Cloudflare Worker 비밀값에만 둔다.

## 지금 하면 좋은 것 (5분)

GitHub 저장소 → Settings에서 켠다.

| 위치 | 켤 것 | 이유 |
|---|---|---|
| Advanced Security | Dependabot alerts, Dependabot security updates | 취약한 패키지를 알려 주고 고치는 PR을 연다 |
| Advanced Security | Secret scanning, Push protection | 실수로 키를 커밋하면 푸시 단계에서 막는다 |
| Advanced Security | Private vulnerability reporting | `SECURITY.md`가 이 경로로 제보를 받는다 |
| Branches → Add rule (`main`) | Require status checks: `check`, `analyze (javascript-typescript)`, `analyze (actions)` | 검사가 실패한 코드는 main에 들어가지 않는다 |

열려 있는 Dependabot PR #1~#6은 닫는다. #1~#5(Actions 버전 올리기)는 이미 커밋 SHA 고정으로 반영했고, #6(@types/node 26)은 Node 24를 쓰므로 받지 않는다(설정에서 앞으로 제외됨).

## 단계 0: 휴대폰 입력 시험

1. 휴대폰에서 사이트 → "내 키보드로 입력 시험하기"를 연다.
2. 일본어(12키 플릭, QWERTY 로마자)와 대만어(주음)로 예문을 한 줄씩 친다.
3. "키보드 이름" 칸에 쓰는 키보드를 적고 JSON을 내려받아 보내 준다.

이 결과로 휴대폰 키 안내를 실제 조합 방식에 맞춘다.

## 유튜브·목소리·넷플릭스 켜기: 키 받기와 중계 서버 배포

중계 서버 코드(`worker/`)는 다 만들어 두었다. 아래를 하면 유튜브 검색·자막, 여자/남자 목소리, 넷플릭스 작품 추천(TMDB)이 켜진다. 하기 전에는 사이트가 "준비 중"을 알리고 기본 연습·대본·기기 목소리로 동작한다.

### 1. 키 받기

모두 무료 등급으로 시작한다. 결제 수단을 요구하면 예산 알림을 0원 근처로 걸어 둔다. 키는 채팅·이슈·커밋에 붙여 넣지 않는다.

| 서비스 | 쓰는 곳 | 할 일 | 넣을 이름 |
|---|---|---|---|
| Google Cloud | 유튜브 검색 | 프로젝트 만들기 → YouTube Data API v3 사용 설정 → 사용자 인증 정보 → API 키 → 키 제한에서 "YouTube Data API v3"만 허용 | `YOUTUBE_API_KEY` |
| SearchAPI(searchapi.io) | 유튜브 자막 | 가입 → API 키. 무료 횟수와 초과 요금을 확인 | `TRANSCRIPT_API_KEY` |
| Azure Speech | 여자/남자 목소리 | Azure 가입 → 리소스 만들기 → Speech(가격 F0) → 키 1과 지역(예: koreacentral) | `AZURE_SPEECH_KEY`, `AZURE_SPEECH_REGION` |
| Azure Translator | 한국어 자막이 없을 때 번역 | 같은 계정에서 Translator(가격 F0) → 키 1과 지역 | `AZURE_TRANSLATOR_KEY`, `AZURE_TRANSLATOR_REGION` |
| TMDB | 넷플릭스 작품 추천 | 가입 → 설정 › API → **API 읽기 액세스 토큰**(긴 토큰, API 키 아님) | `TMDB_TOKEN` |

하나만 있어도 그 기능은 켜진다(예: TMDB 만 넣으면 넷플릭스 추천만).

### 2. 중계 서버 배포 (Cloudflare, 한 번만)

```bash
cd worker
```

```bash
npx wrangler login
```

```bash
npx wrangler kv namespace create CACHE
```

나온 `id` 를 `worker/wrangler.toml` 의 `REPLACE_WITH_KV_ID` 자리에 넣는다. 그다음 키를 하나씩 넣는다(명령을 치면 키를 붙여 넣으라고 묻는다).

```bash
npx wrangler secret put YOUTUBE_API_KEY
```

같은 방식으로 `TRANSCRIPT_API_KEY`, `AZURE_SPEECH_KEY`, `AZURE_SPEECH_REGION`, `AZURE_TRANSLATOR_KEY`, `AZURE_TRANSLATOR_REGION`, `TMDB_TOKEN` 을 넣는다.

```bash
npx wrangler deploy
```

끝에 나오는 주소(예: `https://language-grade1.<계정>.workers.dev`) 뒤에 `/health` 를 붙여 열었을 때 `{"ok":true,...}` 가 나오면 된다.

### 3. 사이트에 주소 알려 주기

GitHub 저장소 → Settings → Secrets and variables → Actions → **Variables** 탭 → New repository variable: 이름 `VITE_WORKER_ORIGIN`, 값은 위 주소(끝에 `/` 없이). 그다음 Actions → 검사와 배포 → Run workflow 로 다시 배포한다. CSP 가 이 주소만 허용하게 바뀐다.

### 4. 알려 주기

배포했다고 알려 주면, 자막 서비스의 실제 응답 모양에 맞춰 어댑터(`worker/src/transcript.ts`)를 확인·조정한다. 지금은 문서를 보고 추정한 모양이다.
