# 언어 1급 — 캐릭터 말투와 응원 문구

작성일: 2026년 11월 1일
기획안 14장(친구와 시간 보상)의 세부 문서다. 학습 화면, 친구 바꾸기, 완료 화면, 복습, 상태 안내에서 친구가 하는 말은 모두 이 문서를 따른다.

## 1. 원칙

- **긍정만 말한다.** 응원, 칭찬, 위로, 쉬어 가기 권유만 쓴다. 비난, 재촉, 죄책감("벌써 끝?", "또 틀렸네"), 다른 사람과의 비교는 쓰지 않는다. 틀렸을 때도 격려한다.
- **창작 문구다.** 원작 캐릭터의 성격과 분위기를 참고해 새로 쓴다. 공식 대사나 만화 대사를 그대로 옮기지 않는다.
- **짧게.** 말풍선 크기(이미지 패키지 README 기준)에 맞춘다. 넘치면 문구를 줄이고, 말풍선을 키우지 않는다.

| 친구 | 말풍선 | 대사 최대 길이 | 말하는 방식 |
|---|---|---|---|
| 치이카와 | S | 8자 | 감탄사와 동작 |
| 우사기 | S | 8자 | 기합 소리와 동작 |
| 쿠리만쥬 | M | 14자 | 짧고 묵직한 한마디와 동작 |
| 하치와레, 모몽가, 시사, 랏코, 카니 | L | 24자 | 문장 |

- **동작은 따로 적는다.** 괄호 안 동작 설명은 말풍선 안에 넣지 않고, 말풍선 아래 회색 작은 글씨(#505050, 14px)로 보여 준다. 화면 읽기 프로그램에는 "치이카와: 와아…! 눈을 반짝이며 박수"처럼 이어서 읽힌다.
- **이모지는 쓰지 않는다.** 감정은 글자와 캐릭터 포즈로 보여 준다.
- **사용자를 부르는 말:** 이름을 묻지 않는다. 반말 친구(하치와레, 모몽가, 카니, 쿠리만쥬)는 "너", 존댓말(시사)은 부르지 않고 말을 건다, 스승(랏코)은 "제자"라고 부른다. 치이카와·우사기는 부르지 않는다.

## 2. 언제, 얼마나 말하나

| 상황 키 | 언제 | 빈도 |
|---|---|---|
| `hello` | 학습 화면에 처음 들어왔을 때 | 매번 |
| `line` | 줄을 마쳤을 때 | 5줄에 한 번 이하, 무작위 |
| `streak` | 3줄 연속 한 번에 맞혔을 때 | 그때마다(단, `line`과 같은 줄이면 `streak`만) |
| `oops` | 같은 줄에서 두 번째 틀렸을 때 | 한 줄에 한 번 |
| `comeback` | 틀렸던 줄을 다시 맞혔을 때 | 그때마다 |
| `step` | 5분 단계가 바뀌었을 때(30·60분 제외) | 단계마다 |
| `rest` | 30분이 되었을 때 | 한 번 |
| `sixty` | 60분이 되었을 때 | 한 번 |
| `finish` | 재료를 끝까지 쳤을 때(완료 화면) | 매번 |
| `review` | 오늘의 복습을 시작할 때 | 매번 |
| `welcome` | 다음 날 이상 지나서 다시 왔을 때(시작 화면) | 하루 한 번 |

- 말풍선은 4초 보이고 사라진다. 입력을 막거나 문장을 가리지 않는다.
- 같은 상황에서 같은 문구를 연달아 쓰지 않는다(직전 문구 제외 후 무작위).
- "캐릭터 움직임 줄이기"가 켜져 있으면 `hello`, `step`, `rest`, `sixty`, `finish`만 말한다.
- `step`의 포즈는 `chiikawa-language-assets-v3/docs/캐릭터특성-반영표.md`의 시간별 포즈를 따른다. 문구는 그 포즈와 어울리는 것을 고른다(예: 하치와레 15~25분은 기타 관련 문구).

## 2-B. 5분 단계별 포즈와 말풍선 (`step`, `rest`, `sixty`, 시작은 `hello`)

와이어프레임 11번 화면과 같은 표다. 단계가 바뀌면 이 문구를 먼저 보여 주고, 그 단계 안에서 다시 말할 때는 3장의 같은 상황 문구 중에서 고른다. 포즈 그림은 스프라이트 시트에서 그림 모양대로 떼어 낸 개별 파일 `{친구id}-{nn}.webp`(시작=00, 5분=01 … 60분=12)를 쓴다. 시트를 칸으로 잘라 쓰면 발·꼬리·손이 이웃 칸으로 넘어가 잘리기 때문이다. 모든 그림은 320×320 투명 캔버스에 가운데, 발은 같은 바닥선(y=308)에 맞춘다.

그림은 v3 시트를 쓰되, v3에서 손이 빠진 11칸(치이카와 20·25·45·55분, 하치와레 시작·40·55분, 쿠리만쥬 10·40·55분, 카니 45분)은 v2 시트의 같은 칸을 쓴다. 그래서 친구마다 13장이 모두 다른 그림이다.

## 3. 캐릭터별

### 치이카와

- **성격:** 수줍고 다정하다. 말 대신 감탄사와 표정, 작은 행동으로 마음을 전한다. 기쁘면 눈물이 맺힌다.
- **쓰는 소리:** 와아…!, 으응!, 우…!, 핫…!, 후에…, 히…
- **피할 것:** 긴 문장, 설명, 큰소리.

| 상황 | 문구 (동작) |
|---|---|
| hello | 와아…! (작게 손을 흔든다) · 으응! (노트를 꼭 안는다) |
| line | 핫…! (작게 박수) · 와아… (눈을 반짝인다) |
| streak | 우, 와아아! (눈물이 맺힌 채 엄지를 든다) · 와아아…! (폴짝 뛴다) |
| oops | 으응…! (괜찮다는 듯 고개를 끄덕인다) · 후에… (같이 화면을 들여다본다) |
| comeback | 와아…!! (두 손을 꼭 모은다) · 핫! (기뻐서 빙글 돈다) |
| step | 으응! (주먹을 꼭 쥔다) · 와아… (노트를 다시 편다) |

### 하치와레

- **말투:** 다정한 반말. "~하자!", "~거야!", "역시!". 걱정을 덜어 주는 말.
- **피할 것:** 훈계, 숙제처럼 들리는 말.

### 우사기

### 모몽가

- **성격:** 귀여움을 독차지하고 싶어 하고, 생색을 낸다. 뻔뻔하지만 결국 은근히 치켜세워 준다.
- **말투:** 당당한 반말, 생색. "내가 ~해 줄게", "흥", "꽤 하는데?". 칭찬 끝에 자기 자랑을 살짝.
- **피할 것:** 진짜로 깎아내리는 말, 비꼬기. 생색은 장난스럽게만.

### 쿠리만쥬

- **성격:** 인생을 아는 어른 같은 여유. 말은 짧고, 시원한 음료나 맛있는 안주로 마음을 전한다. 만족하면 "하아―" 하고 숨을 내쉰다.
- **말투:** 아주 짧은 반말. 말줄임표로 시작하는 한마디. "…잘했어", "…좋아".

### 랏코

- **피할 것:** 꾸짖기, 차가운 평가. 엄격함은 말투에만 두고 내용은 늘 격려다.

## 5. 상태 안내와의 관계

- 오류·빈 상태 안내(와이어프레임 10번 화면)의 제목과 설명은 사이트 말투(짧고 다정한 해요체)로 쓴다. 캐릭터 말투로 쓰지 않는다. 정보가 정확해야 하기 때문이다.
- 그 옆의 캐릭터 그림은 지금 함께하는 친구로 바꾼다(와이어프레임의 여러 캐릭터는 예시다).

## 6. 구현 메모

- 문구는 `src/content/friendLines.ts`(가칭) 하나에 `{ [friendId]: { [situation]: Line[] } }` 모양으로 둔다. `Line = { text: string; action?: string }`.
- 친구 id는 이미지 패키지 `manifest.json`의 id를 쓴다: `chiikawa`, `hachiware`, `usagi`, `momonga`, `kurimanju`, `shisa`, `rakko`, `kani`.
- 테스트: 모든 친구에 11개 상황이 있는지, 말풍선 최대 길이를 넘는 문구가 없는지, 이모지가 없는지 검사한다.
- 문구를 늘릴 때도 1장 원칙을 지킨다. 상황마다 2개 이상을 유지한다.
